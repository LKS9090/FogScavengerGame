# 规则教师与示范采集 · v1

本阶段完成 C# 规则教师、可观看演示、批量验证和示范采集。没有开始 BC/PPO，没有产生学习模型，也没有修改 P02 游戏控制方式。

## 直接体验

运行 `Builds/SwitchTraining/FogScavenger.exe`，按 T 切换到规则教师。按 N 切换配置，R 重置，T 返回手动，WASD 手动移动，Esc 退出。启动参数 `--teacher-demo` 可直接进入教师模式。Unity 打开 `Assets/Scenes/03_SwitchMotorTraining.unity` 后 Play，同样按 T。

教师会自动移动、绕开当前简单障碍、接近开关减速、停稳保持 3 秒。训练场在成功后自动开始下一轮，这是实验工具的回合行为；正式游戏中任务完成等待玩家命令的设计不变。

## 教师具体是什么

`Assets/Scripts/Training/SwitchRuleTeacher.cs` 的 `Decide(float[] observation)` 是完整决策入口，只接收模型同样能获得的 28 项观察，返回世界 X/Z 两个动作。它没有读取地图、配置编号、目标绝对坐标或规划好的路线，没有隐藏记忆，也不使用 NavMeshAgent。

第一版采用局部避障控制：相对目标提供前进方向；16 条射线中距离小于 1.6 米的墙产生避让方向；正常最高速度 3 米/秒，接近目标按距离减速，明显偏离目标方向绕障时减速，距目标中心小于 0.18 米时输出零动作。移动仍通过 RobotMotor 执行，受原有碰撞和加速度约束。

这是一条通用局部控制规则，不是固定秒数的路线脚本。它针对当前平地、单块中央障碍建立基线，不是完整路径规划器。凹形障碍、死胡同、窄通道和动态障碍可能让局部规则卡住，不能直接声称适用于整个 P02 多层地图。若后续扩大任务，应补充验证或升级规划和观察接口。

## 实际验证结果

- 最终交付 exe 批量执行 256 回合，256 成功，全部零碰墙；平均约 7.995 秒，范围 7.00–8.60 秒，包含最后 3 秒保持。
- 配置 0–15，每个 16 个起点偏移/朝向变体。起点在原始位置的 X/Z 各 ±0.6 米范围内变化，朝向随机；目标和障碍使用既定配置。
- 随机种子为 `42000 + configuration * 100 + variant`。variant 0–11 作为训练示范（192 回合），12–15 为验证（64 回合）。
- 训练 15,347 条、验证 5,121 条决策记录；失败或碰撞回合写入 rejected.jsonl，本次为空。
- 配置 16–19 没有参与本次教师开发或示范采集。验证集只是已知布局的新起点，不代表未见地图泛化成绩。
- 每次决策重复执行 5 个 0.02 秒物理步，终止时可不足 5 步。批量加速直接调用相同动作入口进行真实 CharacterController 碰撞移动，不是轨迹计算后瞬移。
- 原环境验收和 Python UnityEnvironment 握手、动作、终止与重置回归检查通过。

成功率描述的是规则教师在上述固定测试分布的成绩，不是学习模型的成绩。初始朝向对本任务影响有限，因为动作定义为世界 X/Z 平移，不依靠朝向决定前进方向。

## 数据与复现

解压后的数据在 `Training/Data/SwitchTeacher-v1/`（Git 忽略），可移植压缩包在 `Training/Datasets/switch-teacher-v1.zip`。每行 JSON 包含：

| 字段 | 含义 |
|---|---|
| observation | 动作执行前的 28 个观察数值，模型输入 |
| action | 教师输出的 2 个动作数值，模仿标签 |
| next_observation | 执行动作后的观察，用于校验或后续算法 |
| configuration / variant / decision | 场地、回合变体和回合内决策序号，仅数据索引，不是模型输入 |
| physics_steps | 本次动作实际重复的物理步数 |
| reward / terminal / truncated / outcome | 即时奖励及本轮终止状态 |
| schema / teacher / split | 数据格式、教师版本和数据划分 |

校验器检查 28/2 维度与有限数值、动作范围、时间对齐、前后观察连续、记录动作与实际动作一致、重置清零、成功时确实压住并停稳 3 秒、整回合划分及预留场地未混入。

这些是用于后续自定义 PyTorch BC 数据加载的 JSONL，**不是 ML-Agents 原生 .demo 文件**，不能直接把 zip 路径填进 ML-Agents 的 demo_path。下一步应编写对应的数据加载器，明确只使用 observation 和 action 进行 BC；若选择官方 BC 管线，需要另行录制/转换兼容的 .demo 并验证。

在工程根目录 PowerShell 执行：

```powershell
& .\Builds\SwitchTraining\FogScavenger.exe -batchmode -nographics --teacher-collect
```

新数据写入 `%USERPROFILE%/AppData/LocalLow/LKS9090/FogScavenger Switch Lab/TeacherRuns/时间戳/`，`teacher-latest.txt` 指向最新目录。每次新建目录，不覆盖既有示范。

```powershell
& C:\Users\kanshan\anaconda3\envs\fog-mlagents\python.exe Training/validate_teacher_data.py Training/Data/SwitchTeacher-v1
```

报告见 `Reports/SwitchTeacher/`；数据文件和教师源文件 SHA256 见 `Training/Datasets/switch-teacher-v1-manifest.json`。重新构建使用 Unity 菜单 FogScavenger / Build Switch Motor Training。构建会写入同一个 SwitchTraining 目录，先退出运行中的训练程序。
