# P02 多层空间与协作灰盒

2026-09-12：按用户确认的三张概念图实现第一版，等待用户试玩反馈。这是 P02 的一个协作候选与空间原型，不代表整阶段或训练环境 E1 已验收。

## 启动与操作

独立程序：`C:\Users\kanshan\FogScavengerGame\Builds\P02\FogScavenger.exe`。
Unity 场景：`Assets/Scenes/02_MultilevelCoop.unity`。

|---|---|

| Esc | 退出独立程序 |

## 先试玩这条路线

1. 起点左前方是高台的楼梯与坡道；上楼梯，再从坡道下来。机器人默认跟随。
2. 探索低地与干涸泳池，沿楼梯下去，从另一端回到地面。护栏限制边缘掉落，双方不跳跃、不攀爬、不游泳。
3. 进入有屋顶的建筑，屋顶自动隐藏。离开后恢复显示；室内墙体保留真实碰撞和遮挡。
4. 右键建筑第一间房的黄色地面开关，让蓝色机器人站上去。它到达后等候，可以点击“继续等候”。
5. 中间门开启，人物通过门，靠近黄色方块按 E 拾取。
6. 先返回开关这一侧，再按 F 召回，带物品走出建筑，出现协作完成提示。按 R 重试。

过早召回会使机器人离开开关、门关闭；可以再次命令它压住开关。门口有人时门保持打开，避免夹住角色。第二个建筑出口在第一间房，不能绕过协作门直接进储物间。

## 本轮可调整的初始规格

| 项目 | 当前实现 |
|---|---|
| 地图范围 | 约 40 × 40 米，紧凑灰盒 |
| 高台 / 低地 / 泳池 | 相对平地 +3 / -1.5 / -3 米 |
| 建筑 | 单层、约 16 × 12 米、两间房、两个外门，无二楼 |
| 相机 | 固定斜俯视，约 50 度向下，斜向观察；正交半高 10.5 米，跟随人物平移及高度，不自由旋转 |
| 人物 | 高 2 米，控制器半径 0.4 米；行走 4 米/秒，跑步 6 米/秒 |
| 机器人 | 视觉高 1.2 米；导航半径 0.35 米，速度 6.5 米/秒，跟随近距离停止 |
| 楼梯 / 主要门洞 | 楼梯宽 3 米，建筑门洞宽 2 米 |
| 楼梯执行 | 可见台阶，连续坡面碰撞与导航；不是关节级迈步训练 |
| 到点行为 | 默认跟随；显式到点后原地等候，提示召回或继续等候 |
| 拾取 | 近距离且无遮挡，实际物品状态变化，不可重复拾取 |

地图大小、相机和移动参数仍是待试玩的原型值，没有宣布冻结为正式训练条件。

## 感知与训练边界

- 机器人使用预烘焙导航，知道玩家指定的目标；跟随使用人物脚底高度，不再把所有目标压到零高度。
- 对本场景唯一任务物品，机器人感知限制为 8 米以内且视线不被墙、门等实体遮挡；开门后透过门洞看到物品属于正常结果。
- 隐藏屋顶只为玩家显示/鼠标选点服务，不移除墙体遮挡。当前不做未知地图探索，不包含敌人或视觉神经网络。
- `item_visible_to_robot` 记录真实视线结果。全局位置、任务状态等其余日志字段用于调试，不应未经筛选直接作为未来策略观察输入。
- 本版使用规则导航和真实交互，没有新增训练、模型权重或训练奖励。用户试玩确认后再确定首个学习任务、观察动作接口、布局变体及训练/测试划分。

## 维护入口

- `Assets/Scripts/P02/P02Player.cs`：屏幕方向移动、跑步与重置。
- `Assets/Scripts/P02/P02World.cs`：相机、屋顶、门/开关/物品、感知、命令与日志。
- `Assets/Scripts/P01/RobotCompanion.cs`：复用导航；新增高度跟随开关，仅 P02 启用，P01 行为保持原设置。
- `Assets/Scripts/P02/P02Acceptance.cs`：只有显式自测参数才启用，正常游戏不自动操控人物。
- `Assets/Editor/P02SceneBuilder.cs`：一次性搭建源码；已有场景时拒绝重复生成。菜单 FogScavenger → Build P02 Greybox 只构建，保留场景修改。
- `Assets/P02Generated`：灰盒材质、坡面网格和导航数据。修改地形后须重新烘焙 NavigationGeometry 的 NavMeshSurface 并保存数据。
- `Training/validate_p02_log.py`：标准库校验自测日志，命令为 `python Training/validate_p02_log.py Reports/P02/acceptance-session.jsonl`。

正常运行日志位于 `%USERPROFILE%\AppData\LocalLow\LKS9090\FogScavenger P02\P02Logs`；每会话单独文件，观察约 5 Hz，事件即时写入，带环境/控制器版本。玩家位置为中心，机器人为脚底，Unity 米制 Y 向上，时间为回合模拟秒数。
